# Contributing to BRUN0R2

Thanks for taking the time to contribute! This repository is a personal GitHub
profile README, but suggestions, fixes, and improvements are welcome.

## How to contribute

1. Fork the repository and create a branch from `main`.
2. Make your changes.
3. If you touched SVG, Markdown, or workflow files, run the validation steps
   locally (see [Validation](#validation)) or let the CI check them.
4. Open a pull request against `main` with a clear description of what changed
   and why.

## Profile cards

The files `profile/stats.svg` and `profile/top-langs.svg` are auto-generated by
the GitHub Actions workflow at `.github/workflows/profile-cards.yml`. Do not
edit them by hand — they are regenerated on a schedule and any manual edits will
be overwritten.

## Validation

This repository validates that all SVG files are well-formed XML and that
`README.md` is present. The check runs on every push and pull request via
`.github/workflows/validate.yml`.
