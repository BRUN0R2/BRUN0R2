# Security Policy

## Supported Versions

This repository is a personal GitHub profile README and does not ship software,
so there are no versioned releases to support.

## Reporting a Vulnerability

If you discover a security issue (for example, exposed secrets in a workflow,
a malicious SVG, or a supply-chain concern in a GitHub Action), please do not
open a public issue. Instead, contact the repository owner directly through
GitHub or the channels linked in the README.

Please include:

* A clear description of the issue and its impact
* Steps to reproduce or verify the problem
* Any suggested fix or mitigation

We will acknowledge receipt of your report and work with you to resolve it.

## Scope

* `README.md`, `assets/profile-banner.svg`, and the `profile/` cards
* `.github/workflows/` (GitHub Actions)

## Policy

We do not offer bounties or rewards for security reports, but we appreciate
your effort to keep this profile safe.
